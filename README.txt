# FoodieHub — Food Ordering Website

## How to run
1. Extract the ZIP file.
2. Open the `FoodieHub` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

For the AngularJS features, an internet connection is needed because AngularJS and food photos are loaded from online CDNs/image URLs.

## Features
- Responsive home page and food categories
- Search and category filtering using AngularJS
- Sorting by price and rating
- Add to cart, quantity controls, remove items
- Automatic subtotal, delivery fee, and total calculation
- Checkout form validation and order confirmation
- Offer banners, toast notifications, CSS animations
- Mobile navigation menu

## Notes
This is a front-end college project/demo. Orders are not sent to a real restaurant, customer information is not stored on a server, and online payments are not processed. Do not enter real sensitive information.

## Technologies
HTML5, CSS3, CSS3 animations, JavaScript, AngularJS 1.x
